Smart Bakery Bot 🍞
Smart Bakery Bot is a simple, friendly chatbot designed to help a bakery interact with customers. It can answer questions about the menu, take orders, and provide quick information — all powered by Python.

Features
	* 🥐 Browse bakery menu items
	* 💬 Answer customer questions
	* 🛒 Take and manage simple orders
	* ⚙️ Easy to configure via menu.json

Getting Started
Prerequisites
	* Python 3.8 or higher
	* pip (Python package manager)

Installation
	1. Clone the repository:

git clone https://github.com/ajimol960-blip/smart-bakery-bot.git
cd smart-bakery-bot

	2. Install the required dependencies:

pip install -r requirements.txt

	3. Run the bot:

python app.py


Project Structure
smart-bakery-bot/
├── .devcontainer/     # Development container configuration
├── libs/              # Helper libraries and modules
├── app.py             # Main application file
├── menu.json          # Bakery menu data
├── requirements.txt   # Python dependencies
└── README.md          # Project documentation

Configuration
Edit menu.json to customize the bakery's menu items, prices, and descriptions.
